# Noor Kids Hub 🌙✨

**Noor Kids Hub** is a cheerful, interactive educational web platform designed as a "digital garden" for children in Pakistan and Muslim kids everywhere. The project aims to flip traditional, rigid learning methods upside down by making Islamic education playful, rewarding, and deeply engaging through gamification.

Captured from a pixel-perfect front-end design, the interface welcomes young learners with bright colors, cheerful sounds, visual badges, and a friendly moon mascot celebrating every achievement.

---

## 🎯 Key Features

- **Gamified UI/UX:** Built with a kid-friendly layout, visual reward stars, and responsive elements.
- **Family-Centric Learn Section:** Designed for kids to play interactive games and quizzes, while parents can track progress or learn alongside them.
- **Progress Tracking:** Includes mock mechanics for earning XP, collecting stars, and tracking interactive milestone levels.
- **Localized Touch:** Tailored explicitly for Pakistani Muslim families, integrating familiar Urdu aesthetics and welcoming cultural greetings.

---

## 🛠️ Tech Stack & Concepts Explored

This project was built from scratch without external heavy UI libraries to master core front-end foundations:

- **HTML5:** Semantic architecture optimized for clean layouts.
- **CSS3:** Custom layout adjustments, animations, and color palettes designed to keep children engaged.
- **Vanilla JavaScript:** Interactive DOM manipulation, logic handling for quizzes, and tracking state transformations (XP/Stars).
